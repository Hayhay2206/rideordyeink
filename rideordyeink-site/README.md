# Ride or Dye Ink Website

Free static website for rideordyeink.com.

## Files
- `index.html` - website content
- `styles.css` - website design

## Hosting
This site can be hosted free on GitHub Pages, Netlify, or Cloudflare Pages.

## Customizing
Replace placeholder gallery blocks with real images of Ride or Dye Ink work.
For artwork uploads, create a Google Form and replace the quote button/form link.
